마이리얼트립으로 항공권이나 숙소를 예약하기 전에는 할인코드를 먼저 확인해두는 것이 좋습니다. 코드마다 적용되는 상품과 할인율이 다르기 때문에, 결제 화면에서 급하게 찾기보다 미리 정리해두는 편이 시간을 아낍니다. 아래에서 지금 확인된 코드와 사용 방법을 정리했습니다.

마이리얼트립 쿠폰 코드, 종류부터 확인하기

여행 예약 사이트마다 발급하는 쿠폰의 성격이 조금씩 다릅니다. 마이리얼트립 쿠폰은 항공권, 숙소, 투어·액티비티 상품별로 코드가 나뉘어 있어서, 예약하려는 상품에 맞는 코드를 골라 써야 합니다. 코드를 잘못 넣으면 할인이 적용되지 않거나 오류가 뜨는 경우도 있으니, 코드 이름과 할인율을 한 번 더 확인하고 입력하는 것을 추천합니다.

지금 확인된 코드는 다음과 같습니다.

  • FFF8E6
  • LINKPRICE — 0% 할인
  • PACKMKTP — 3% 할인
  • LINKPRICE6000 — 0% 할인
  • LINKPRICE3000 — 0% 할인
  • LINKPRICE2000 — 0% 할인
  • PACKMKTP5000 — 3% 할인
  • PACKMKTP3000 — 0% 할인
  • PACKMKTP1000 — 0% 할인
  • LINKPRICESTAY3000 — 0% 할인
  • LINKPRICESTAY1000 — 0% 할인
  • GLOBAL — 40% 할인

할인율이 0%로 표기된 코드는 적립이나 특전 조건이 붙어 있는 경우가 많으니, 결제 전 안내 문구를 함께 확인해보시기 바랍니다. GLOBAL 코드처럼 할인율이 높은 코드는 사용 조건이 제한적일 수 있어 예약 상품과 기간을 다시 한 번 살펴보는 것이 안전합니다.

항공권·숙소 예약에 쓸 코드 고르기

항공권이나 숙소를 예약할 때는 LINKPRICE 계열과 PACKMKTP 계열 코드를 먼저 확인해보시면 됩니다. LINKPRICESTAY3000, LINKPRICESTAY1000처럼 숙소 예약 전용으로 보이는 코드도 있으니, 항공과 숙소를 나눠서 코드를 적용해보는 것도 방법입니다.

코드를 입력해도 화면에 반영이 늦게 뜨는 경우가 있어서, 최종 결제 금액을 한 번 더 확인한 뒤 결제를 진행하시는 것이 좋습니다. 할인율과 조건은 예고 없이 바뀔 수 있으니, 예약 시점에 적용 여부를 다시 확인해보시기 바랍니다.

쿠폰 적용할 때 놓치기 쉬운 부분

쿠폰 코드는 대소문자를 구분하는 경우가 있어서, 목록에 적힌 그대로 입력하는 것이 안전합니다. 또한 한 번에 하나의 코드만 적용되는 경우가 많으므로, 여러 코드를 동시에 넣기보다는 할인율이 더 큰 코드를 우선 적용해보고, 안 되면 다른 코드로 바꿔보는 방식을 추천합니다.

쿠폰 조건은 시즌이나 재고 상황에 따라 변동될 수 있습니다. 예약 직전에 코드가 정상적으로 적용되는지 결제 화면에서 다시 한 번 확인해보시기 바랍니다.

자주 묻는 질문

Q. 쿠폰 코드는 어디에 입력하나요? 결제 단계의 쿠폰 코드 입력란에 목록에 있는 코드를 그대로 입력하면 됩니다.

Q. 할인율이 0%로 표시된 코드는 왜 있나요? 할인 대신 적립이나 다른 혜택 조건이 붙어 있는 코드일 수 있어, 결제 화면 안내를 함께 확인하시는 것이 좋습니다.

Q. 코드가 적용되지 않으면 어떻게 하나요? 예약하려는 상품 종류(항공권·숙소·투어)에 맞는 코드인지 다시 확인하고, 대소문자를 그대로 입력했는지 점검해보시기 바랍니다.
